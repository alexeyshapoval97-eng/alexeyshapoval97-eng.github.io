Excel

Калькулятор стоимости заказа

Задача
Менеджерам нужно быстро считать цену сборки пакетов: тираж, ручки, дополнительные опции.
Сделано
Книга Excel с вводом в жёлтых ячейках и выпадающих списках. Прайс на отдельном листе, тираж между ступенями считается по ближайшей ступени вниз.
Итог
Цена за штуку и за весь тираж сразу. Новый прайс вносится на свой лист, формулы трогать не нужно.

Excel + VBA

Пропуска в один клик

Задача
Заявки на пропуск для людей, транспорта и ТМЦ заполняли в Word по разным шаблонам.
Сделано
Одна форма заявки на четыре сценария. Бланк печатается так же, как в Word, а справочник подписантов правится без программиста.
Итог
Кнопка «Сохранить PDF» кладёт готовый бланк в архив, в имени файла дата и фамилия.

Excel + Python

Разбор расхода материалов

Задача
Понять, почему план потребления материалов изменился между двумя циклами планирования SOP.
Сделано
Скрипт сводит выгрузки из SAP (остатки, производственные заказы, спецификации) с планом и раскладывает разницу по причинам. Результат лежит в книге Excel для аналитиков.
Итог
Сверка с ручным расчётом: 0 расхождений. Новый цикл собирается одним запуском.

Excel + Python

Прогноз продаж с местом отгрузки

Задача
К прогнозу продаж добавить склад, с которого поедет каждая позиция.
Сделано
Склад подтягивается из истории фактических отгрузок по паре «клиент — филиал». Названия филиалов приводятся к одному виду, новые клиенты по правилу уходят на свой региональный склад.
Итог
Готовая таблица для следующих расчётов и сводка о том, сколько строк сопоставилось, после каждого запуска.

Дашборд

Дашборд задач по запасам

Задача
Команда ведёт задачи по запасам в общем Excel-файле. Нужно видеть общую картину без ручных фильтров.

Страница собирается из листа активных задач рабочего файла: сколько задач открыто и в каком они статусе. Открывается в браузере и на корпоративном портале.
Итог
Все задачи на одном экране, а данные команда ведёт в привычном файле.

Частые вопросы

Данные у нас закрытые. Так можно работать?

Да. Пришлите файл с изменёнными цифрами: для работы важна структура, а сами значения можно заменить. Если нужно, подпишем соглашение о неразглашении.

У нас Mac или Google Таблицы. Это важно?

Важно, поэтому скажите сразу, где будут открывать файл. Формулы работают везде, а макросы VBA только в настольном Excel. Для Google Таблиц и Excel Online сделаю без макросов.

Нужен ли Power BI или другая платная система?

Нет. Дашборд делаю одним файлом: он открывается в любом браузере и на корпоративном портале, лицензии не нужны.

Где будет работать сайт?

Помогу выбрать хостинг и домен и опубликовать сайт. Простому сайту часто хватает бесплатного хостинга.

Что делать, когда придут новые данные?

Отчёт делаю так, чтобы его можно было обновлять самим: положили новую выгрузку, нажали кнопку. К файлу прилагаю короткую инструкцию.
